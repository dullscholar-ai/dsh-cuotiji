# 错题本

把试卷、作业、练习册变成可以按知识点反复查阅的错题集。

## 它能做什么

- **上传并识别**：图片（手机拍的卷面、长截图）、PDF、Markdown、纯文本都可以。面板里拖进文件后，模型会逐题读出题干、小问、选项、表格与配图位置。
- **双轨保存**：每道错题同时保存两份东西 —— 结构化文本（便于检索、生成解析、排版导出）和原卷裁切图（保证细节不失真）。题干文字不会被改写，识别不确定的地方保留原样并标注。
- **按知识点归集**：学科 → 章节 → 知识点 三级分类，再叠加自由标签。面板左侧的树用于筛，顶部搜索框可跨题干、知识点、出处直接搜。
- **逐题复核**：点开任一题可以对照原卷图修改题干、解题过程、答案与分类，改完保存即写回工作区文件。
- **批量删除**：左边的方框勾中多道题后点「删除选中」，二次确认后一并删除，题目 JSON 与 `assets/<题号>/` 配图目录都会被清掉；找不到的 id 会单独报告，不影响其余题目删除。
- **想导哪些就导哪些**：四种「选什么」可以单独用，也可以叠加——
  1. 点列表左边的方框**手选任意几道**（跨册、跨学科都行），或按「全选」把当前筛选结果一次勾上；
  2. **按日期区间**（入库时间，含首尾整天）；
  3. **按学科 / 册 / 章 / 节**（左树点选）；
  4. **按关键词**搜索题干、解析、答案、出处。
  手选优先：只要勾了题，导出就只导勾中的那些；没勾就按当前筛选结果导。
- **固定版式导出**：一题一页 A4，题头（题号｜学科·册·章·节）、① 原题（题干、小问，紧跟该题的原卷裁切图）、② 解题过程、③ 答案（浅灰底纹）四个区块。一次导出同时产出三种文件：`.pdf`（成品）、`.docx`（可再编辑的源件）、`.html`（浏览器打印即 PDF）。也可以按知识点分册，每册一套三件。

## 上传原卷后会发生什么

点「交给模型识别」时，链路是：**本机 OCR → 交给模型 → 模型逐题入库**。

1. 原卷先存进 `错题本/_inbox/`（保留原件，不裁切）。
2. 插件在**本机**用 RapidOCR（PP-OCR，onnxruntime 后端）把每张图片识别成文字，约 5–15 秒/页。
   - 图片**不上传**到任何服务器。
   - 识别结果按「左栏自上而下 → 右栏自上而下」重排——试卷常是双栏，不做这一步会串序。
   - 全文落到 `错题本/_inbox/_ocr/<原名>.ocr.txt`（含每段的栏位与坐标），模型随时可再读。
   - 每台机器只探测一次解释器；找不到装了 `rapidocr_onnxruntime` 的 Python 就跳过 OCR，退化成直接读原图，不会报错卡住。
3. 模型同时拿到**原图路径 + OCR 全文**：以文字为底稿逐字录入，用原图核对分栏、图形与手写答案。
4. 提示词里明确要求：OCR 的错讹**不许静默改通顺**，必须写「⚠ 识别存疑：……」并保留原文。

想换引擎或指定解释器：设环境变量 `CUOTIJI_PYTHON` 指向装了 `rapidocr_onnxruntime` 的 `python.exe`。

## PDF 是怎么生成的

PDF 走的是「先排 docx，再用本机 Office 另存为 PDF」这条路——这样页眉、页脚页码、一题一页的分页与 `.docx` 完全一致，不会出现两套实现各排一遍导致的走样。

- 优先调用 `Word.Application`，没有则退回 `KWps.Application`（WPS 文字）；两者都通过 COM 的 `ExportAsFixedFormat(..., 17)` 导出。
- 不受别的程序影响：不会把你自己开着的 Word 窗口藏掉，也不会关掉你正在编辑的文档；只有在「导出前 Office 本来没在运行」时才顺手退出。
- 本机完全没有 Office 时，退回用本机 Chrome / Edge 无头打印 HTML——版式仍是一题一页，但**没有页眉、页脚和页码**，导出结果里会带一条提示说明这一点。
- 一次导出大约 5–12 秒（主要是 Office 启动），分册导出按册数累加；面板上会显示「PDF 排版中…」。

## 归类：必须落在浙江在用教材目录里

错题的章节不再由模型随手写。学科 → 册 → 章 → 节的坐标来自 `lib/taxonomy/*.json`，是**白名单**：

- 入库前模型要先调 `cuotiji_taxonomy` 取该学科的目录原文，再逐字填 `chapter` / `section`；
- 归错章会被 `cuotiji_save` 直接拒绝，并返回最接近的候选（按标题相似度排序），不给「换个写法硬试」的机会；
- 匹配对空格、全半角、括号、「第N章」编号前缀都做了归一，所以「第1章探索自然的科学」也能对上；
- `topics` 仍然是自由标注的知识点标签，不受目录限制——章节归类是硬约束，知识点是软标签。
- 某一科还没有目录数据时放行（不会把插件卡死），面板会显示该科「无目录」。

**第一批（初中 7–9）已收录**：

| 学科 | 版本 | 规模 |
|---|---|---|
| 科学 | 七上/七下 2024 版；八、九年级 2013 修订版 | 6 册 / 26 章 / 134 节 |
| 数学 | 浙教版 | 6 册 / 30 章 / 148 节 |
| 语文 | 部编版（2016 版） | 6 册 / 36 单元 / 231 条 |
| 英语 | 外研版 | 6 册 / 68 模块 / 67 小节（34 个模块只到模块级） |
| 道德与法治 | 统编版（七/八/九上 2024，九下 2016 待核） | 6 册 / 23 单元 / 65 课 |
| 历史与社会 | 人教版（该课程浙江已于 2020 年停用） | 6 册 / 24 单元 / 87 课 |

数据里每一项都带 `unverified` 标记，面板与 `cuotiji_taxonomy` 会把「待核」的条目显式标出来，不假装准确。

## 数据放在哪

工作区下的文件夹就是真相源，面板只是它的浏览器：

```
错题本/
├── _inbox/                    上传但还没识别的原件
├── 数学/
│   ├── 二次函数最值-0001.json
│   └── assets/二次函数最值-0001/stem.png
└── 数学/keypoints.md          该学科的知识点大纲（可选）
错题导出/
```

- 一题一个 JSON，纯文本，可以直接编辑、复制、纳入 git。
- 原卷图存在同目录的 `assets/<题号>/` 下，JSON 里用相对路径引用。
- 目录名与字段名按你的需要改都行，重命名后重新打开面板即可。

## 怎么用

1. 打开左侧栏的**错题本**面板。
2. 把试卷截图 / PDF 拖进上传区。文件会被存到 `错题本/_inbox/`，同时当前会话里会收到一条识别指令。
3. 模型识别完会调用入库工具，题目随即出现在面板列表里。
4. 逐题复核、改分类、补解析。
5. 点「导出」生成 `.docx` / HTML，或直接在会话里用 `/cuotiji export 数学 二次函数`。

## 已知限制

- 识别质量取决于当前会话使用的模型对中文试卷、公式与表格的读图能力；手写批改痕迹、低分辨率拍摄会降低准确率。**面板不会假装识别成功**，没有入库成功时 `_inbox/` 里的原件仍然在。
- 文件读写走本机文件系统，适用于本地工作区；不适用于远程 SSH 工作区。
- 导出的 `.docx` 由插件自己写 OOXML 生成，不经过 Office；复杂公式作为原文保留（`$...$`），不渲染成 Word 公式对象。
- 按知识点分册导出时，一本书只包含该知识点下的题目，题目顺序沿用题号。
